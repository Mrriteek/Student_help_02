# STUDENT HELP – Website (plain HTML/CSS/JS)
1. Open `js/config.js`: set `apiBase` (your backend URL) and the Firebase web config.
2. Upload this folder to any static host (Firebase Hosting, Netlify, Vercel, cPanel). No build step.
3. Backend: see student-help-backend (set FRONTEND_ORIGIN to this site's URL for CORS).
4. Firebase Auth: enable Email/Password + Google, and add your site domain under Authorized domains.
